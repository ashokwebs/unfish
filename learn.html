🐡 Welcome to Unfish

Unfish is a serious, general-purpose programming language, compiler, bytecode virtual machine, and educational computing environment implemented in pure ANSI C99 with zero external dependencies.

"Hide complexity until the learner is ready — never hide it forever."

The Unbroken Path of Intellectual Ascent

Most programming languages force learners into a compromise: either use an overly simplified toy environment (like Scratch or simple web editors) that conceals how computers actually work, or dive directly into complex industrial languages (like C++ or Rust) where boilerplate and cryptic toolchains overwhelm beginners.

Unfish resolves this dilemma through a clean, unified architecture:

  • Level 1: Visual Blocks — Drag, snap, and assemble visual logic blocks with real-time two-way synchronization into source code.
  • Level 2: Clean Scripting — Human-oriented, indentation-based syntax without semicolons or noisy braces.
  • Level 3: Modern Language Engineering — Structs, object methods, algebraic enums, pattern matching, closures, cooperative fibers, and destructuring.
  • Level 4: Computer Systems & Runtimes — Contiguous byte buffers, little-endian access, memory layout inspection, mark-and-sweep garbage collection, and custom bytecode virtual machines.
  • Level 5: Native & WebAssembly Compilation — Compiling directly into standalone, dependency-free C99 machine code and WebAssembly.

The Five-Engine Differential Architecture

Unfish features five distinct execution tiers kept in 100% lockstep by an automated differential conformance suite:

TierEngineDescriptionBest For
1 AST Interpreter Direct syntax tree walking interpreter Interactive REPL, instant startup, visual blocks
2 Stack Bytecode VM 36-opcode stack virtual machine with upvalues 2x–6x execution speedup, instruction tracing
3 Register Bytecode VM 256-register 3-address VM with computed-goto Fast interpreted execution, compiler education
4 Native C99 Compiler AOT transpilation into freestanding C99 30x–200x native execution speedup, binary deployment
5 WebAssembly Target Portable WebAssembly binary output In-browser execution, serverless workers

⚡ Installation & Setup

Unfish requires only a standard C99 compiler (such as gcc or clang) and standard POSIX make. It has zero external dependencies beyond libc and -lm.

Building from Source

Terminal Shell (Bash) 
git clone https://github.com/ashokwebs/unfish.git
cd unfish
make -j4
./bin/unfish version

Running the Test Suites

Verification Commands 
# Run all 21 unit test suites and the 104-test differential conformance suite
make test

# Verify zero memory leaks under AddressSanitizer & UndefinedBehaviorSanitizer
make test-asan

# Run multi-tier performance benchmarks
make bench

💻 REPL & Developer Toolchain

The unfish executable provides a unified interface across the development lifecycle:

CommandPurpose
unfish run <file>Execute script using tree-walking AST interpreter
unfish run --vm <file>Execute script using Stack Bytecode VM
unfish run --regvm <file>Execute script using Register Bytecode VM
unfish build -o <bin> <file>Compile program to native executable binary
unfish build --wasm <file>Compile program to WebAssembly module
unfish format -i <file>Format source code to canonical style in place
unfish debug <file>Launch interactive step debugger with breakpoints
unfish studioLaunch the browser IDE & visual blocks canvas
unfish lspStart Language Server Protocol server for VS Code
unfish replLaunch interactive Read-Eval-Print Loop

02. Values & Primitive Types

        

          Unfish runtime values are represented internally by a 16-byte tagged union (UfValue). The primitive types are:
        

        
    
          
  • Numbers — 64-bit IEEE 754 floating-point numbers (42, 3.14159, 0xFF, 1e6).
    • 
          
  • Strings — Contiguous UTF-8 encoded text with length tracking and string interning.
    • 
          
  • Booleans — true or false.
    • 
          
  • Null — Represents absence of value (null).

sys.set_env(k, v)(String, String) -> BooleanSets host environment variable

            
sys.exec(cmd)(String) -> NumberExecutes shell command via system()
