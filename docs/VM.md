# UNFISH — VIRTUAL MACHINE SPECIFICATION (PHASE 7 ROADMAP)

---

## 1. Architectural Vision

While Phase 1–2 builds a clean, AST tree-walking interpreter to establish canonical language semantics, Phase 7 will introduce a bytecode Virtual Machine (VM).

The VM will execute compact linear instructions on a virtual CPU with an operand stack, instruction pointer, and call stack, allowing students to learn bytecode compilation and VM architecture.

## 2. Preliminary Bytecode Instruction Set Architecture (ISA)

| Opcode | Operands | Description |
|---|---|---|
| `OP_CONSTANT` | `u16 index` | Push constant from pool onto operand stack |
| `OP_NULL` | None | Push `null` |
| `OP_TRUE` | None | Push `true` |
| `OP_FALSE` | None | Push `false` |
| `OP_LOAD_LOCAL` | `u16 slot` | Push local variable at stack slot |
| `OP_STORE_LOCAL` | `u16 slot` | Store top of stack into local stack slot |
| `OP_LOAD_GLOBAL` | `u16 name_idx`| Look up global variable by symbol index |
| `OP_STORE_GLOBAL`| `u16 name_idx`| Set global variable by symbol index |
| `OP_ADD` | None | Pop 2, push sum/concatenation |
| `OP_SUB` | None | Pop 2, push difference |
| `OP_MUL` | None | Pop 2, push product |
| `OP_DIV` | None | Pop 2, push quotient |
| `OP_MOD` | None | Pop 2, push remainder |
| `OP_NEG` | None | Pop 1, negate number |
| `OP_NOT` | None | Pop 1, logical not |
| `OP_EQ` | None | Pop 2, test equality |
| `OP_LT`, `OP_LE` | None | Pop 2, relational test |
| `OP_GT`, `OP_GE` | None | Pop 2, relational test |
| `OP_JUMP` | `i16 offset` | Unconditional relative jump |
| `OP_JUMP_IF_FALSE`| `i16 offset` | Jump if top of stack is falsy |
| `OP_BUILD_ARRAY` | `u16 count` | Pop `count` elements, push array object |
| `OP_INDEX_GET` | None | Pop index and target, push target[index] |
| `OP_INDEX_SET` | None | Pop value, index, target, store target[index] = value |
| `OP_CLOSURE` | `u16 fn_idx` | Instantiate closure with captured upvalues |
| `OP_GET_UPVALUE` | `u8 index` | Read captured upvalue |
| `OP_SET_UPVALUE` | `u8 index` | Mutate captured upvalue |
| `OP_CALL` | `u8 argc` | Call function with `argc` arguments |
| `OP_RETURN` | None | Return from function frame |
| `OP_SAY` | None | Pop 1 and output to standard output |

## 3. Bytecode Disassembler [PLANNED]
A core educational feature: `unfish disasm program.unfish` will display the generated bytecode with source line mappings, enabling students to understand how high-level code translates to VM instructions.

---

## 4. Compilation Pipeline & IR Contract [DESIGN / ADR 013]

```
Unfish Source (.unfish)
        ↓  (Lexer + Parser)
       AST (UfProgram, UfStmt, UfExpr)
        ↓  (Semantic Analysis)
   Typed / Resolved AST
        ↓  (Bytecode Compiler)
   Bytecode Chunk (Instructions, Constants, Line Map)
        ↓  (Unfish VM)
   Stack Evaluation (Virtual CPU)
```

### Invariant Guarantee
The tree-walking interpreter (`uf_interpret_program`) and the future bytecode virtual machine (`uf_vm_execute`) share the exact same runtime values (`UfValue`), garbage collector (`UfObj`), environment object layouts, and native standard library built-ins. Both execution engines are subjected to the identical 23+ conformance test suite to guarantee 100% semantic equivalence.
