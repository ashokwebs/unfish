📥 Official Downloads & Toolchain (v2.0.0)

Unfish is packaged with zero external dependencies. Everything you need — compiler, virtual machines, interactive debugger, formatter, and language server — is bundled in a single self-contained executable.

⚡ One-Line Universal Install

Paste this command into your terminal to install the latest prebuilt Unfish binary to ~/.unfish/bin:

curl -fsSL https://ashokwebs.github.io/unfish/install.sh | bash

⚡ Quick Start & CLI Reference

Once installed, the unified unfish binary provides commands across the entire software development lifecycle:

Command Description
unfish run <file>Execute script via tree-walking AST interpreter
unfish run --vm <file>Execute script via 57-opcode Stack Virtual Machine (2x–6x faster)
unfish run --regvm <file>Execute script via 256-register computed-goto VM
unfish build [-o bin] <file>Compile script directly into native standalone C99 binary (25–60x speedup)
unfish build --wasm <file>Compile script into WebAssembly binary module
unfish format -i <file>Format source code to canonical Unfish style
unfish debug <file>Launch interactive step debugger with breakpoints and stack traces
unfish check [--strict] <file>Validate syntax and gradual type annotations
unfish lspStart Language Server Protocol (JSON-RPC 2.0)
unfish replStart interactive read-eval-print loop
unfish playground [--port <p>]Launch local web playground server
unfish studio [--port <p>]Launch full local browser Studio IDE

🐡 What is Unfish?

Unfish is a real, general-purpose programming language, runtime, compiler, and educational computing environment written in clean ANSI C99 with zero external dependencies.

It is designed to provide an unbroken path of intellectual ascent: from visual block programming, into clean indentation-based text programming, to algorithms, data structures, runtime architecture, garbage collection, bytecode virtual machines, and low-level systems programming.

"Hide complexity until the learner is ready — never hide it forever."

Five Execution Engines in Lockstep

Unfish implements five distinct execution backends, kept in lockstep by a differential test suite that requires byte-identical output from every one of them:

  1. Tree-Walking AST Interpreter: Immediate startup, direct AST evaluation, ideal for REPL and visual block editing.
  2. Bytecode Virtual Machine (--vm): 57-opcode stack VM with lexical upvalue capture cells, exception unwinding, and 2x–6x speedup over AST tree-walking.
  3. Register-Based Bytecode VM (--regvm): 256-register, 3-address VM with computed-goto dispatch.
  4. Native C99 AOT Compiler (build): Direct transpilation into standalone ANSI C99 with single-header runtime, measured at 25–60x faster than AST.
  5. WebAssembly Target (build --wasm): Portable WASM binary running in browsers and edge runtimes.

## 02. Functions and Data Transformations
function calculate_heading(angle, offset):
    return (angle + offset) % 360

say f"New Heading: {calculate_heading(350, 25)} degrees"

🔬 Learn the Computer through Unfish

Unfish unrolls the layers of modern computing through an open 5-stage pipeline:

Layer Component How to Inspect
Layer 1 Lexical Scanning & Tokens unfish tokens <file>
Layer 2 Pratt Parser & Syntax Tree unfish ast <file>
Layer 3 Lexical Scoping & Upvalue Captures unfish compile <file>
Layer 4 Bytecode Virtual Machine ISA unfish disasm <file>
Layer 5 Memory Arenas & Mark-Sweep GC unfish run --vm --debug <file>
